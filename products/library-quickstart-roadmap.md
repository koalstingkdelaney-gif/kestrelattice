# The Complete Library — Quick-Start Roadmap

**You own the whole shelf. This is the order to read it in — exclusive to Complete Library buyers.**

By GhostCorp · Kestrelattice · September 2026

Seven PDFs is a lot of shelf. This short guide exists for one reason: to stop you staring at seven files wondering where to start. Find your situation below, follow the path, and you'll be acting — not reading — inside a week.

## Find your situation

**"We're starting from zero — agents are coming and nothing is governed yet."**
Your path: Studio Edition → Use Case Library → Risk Audit Kit → Prompt Injection Field Guide.
Read the Studio Edition's 14-day rollout first; it is the spine everything else hangs on. Then tier your actual use cases with the library, score your risk with the audit kit, and harden the attack surface before you connect anything real.

**"We already had an incident — or we're afraid of the next one."**
Your path: Incident Response Runbook → Risk Audit Kit → Prompt Injection Field Guide → Studio Edition.
Start with the runbook's first-30-minutes card today — literally today. Then audit what the incident exposed, harden the vector it used, and only then build the standing policies in the Studio Edition.

**"Our agent bill just scared someone in finance."**
Your path: Cost Control Workbook → Risk Audit Kit → Studio Edition.
Do the workbook's budget-design worksheet and kill-on-overspend rules this week. The audit kit then tells you which workloads deserve their budgets; the Studio Edition makes the ceilings permanent policy.

**"Leadership wants a risk review before we scale."**
Your path: Risk Audit Kit → Use Case Library → Quarterly Access Review Kit → Studio Edition.
Run the 18-question assessment and 40-point checklist, tier every live use case, verify who can touch what with the access review — then present the Studio Edition's policy templates as the remediation plan.

**"We're specifically worried about prompt injection / jailbreaks."**
Your path: Prompt Injection Field Guide → Risk Audit Kit → Incident Response Runbook.
Run the 20 adversarial tests against your agents first — you'll learn more in an afternoon than in a month of meetings. Then audit, then make sure the runbook covers the attack working.

## The 30-day sequence (if you have no emergency)

If nothing is on fire, this is the order the library was designed to be consumed in:

**Days 1–7: Foundation.**
Read the Studio Edition's policy templates and pick your three tiers. Fill in the risk-tier worksheet for your five most important agent workloads. Stand up the plan-bound schema for one workload — just one.

**Days 8–14: Inventory.**
Tier every agent use case you can find with the Use Case Library. Run the Risk Audit Kit's assessment and checklist. You now have a map of what you run and how dangerous each piece is.

**Days 15–21: Hardening.**
Run the Prompt Injection Field Guide's adversarial tests against your highest-tier agents. Install the Cost Control Workbook's metering and kill-on-overspend rules. Fix what the tests find.

**Days 22–30: Rhythm.**
Run your first Quarterly Access Review. Walk the Incident Response Runbook as a tabletop exercise with whoever owns the agents. Write the date of the next review on a calendar where you'll see it.
