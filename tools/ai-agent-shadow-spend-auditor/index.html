How the math works

Anticipated daily overhead = agents × anticipated invocations per agent per day × average API cost per invocation. Actual overhead applies the three overhead factors on top: retries, inter-agent handoffs, and orchestration / logging / monitoring. The ghost spending delta is actual minus anticipated — the spend no budget line named, which is exactly the delta a CTO can take to a CFO to justify governance and budget controls.

What to do with the ghost number

  • Cap retries: set a maximum retry count per invocation and log every retry as spend, not as noise.
  • Count handoffs: instrument inter-agent calls so mesh chatter is billed to the task that caused it.
  • Budget the overhead: put orchestration, logging and monitoring in the plan explicitly — hidden only means unowned.
